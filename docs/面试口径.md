# 这个项目怎么讲（面试口径）

> 一句话定位：**自建的竞品价格监控工具，跑在我自己电脑上，真往飞书推过告警。**
> 不要说成公司项目、不要说有线上用户，这是个人工程练习 + 真机跑通。

## 1. HR 面（30 秒，别讲技术细节）

"我做过一个竞品价格监控的小工具。电商运营每天要盯几十个竞品链接看谁降价、谁断货，人工刷很漏。
我写了个程序按点抓这些页面，跟上次的价格比，超过阈值就自动往飞书群推一张卡片，
还会算一句'建议调价到多少'。用的是 Python + SQLite，我本地跑了 25 个测试，也真的把消息推到我飞书群里验证过。"

关键词只出三个：**自动盯页面、飞书告警、给调价建议**。

## 2. 技术面（90 秒）

- 分层：`fetch`（取价）→ `rules`（判定，纯函数）→ `store`（SQLite 快照）→ `notify`（飞书卡片）→ `runner`（串起来 + 常驻循环）
- 取价四级降级：CSS 选择器 → `meta[itemprop=price]` → JSON-LD → 整页正则；静态抓不到可切 Playwright
- 判定六类：降价 / 涨价 / 断货 / 补货 / 被压价 / 连续下跌；同类告警 24 小时内不重复发（避免刷屏）
- 一轮里所有商品合并成**一张卡片**推一次；单商品抓取失败不中断整轮，错误写日志 + 发 `miss` 提醒
- 部署三种：常驻 `watch`（带 ±10% 抖动）、Docker Compose、Windows 计划任务 / cron
- 测试 25 个：特意固化了两个容易翻车的点——**同一秒插入两条快照要取 id 更大的那条**、**飞书 HMAC 签名用参考向量对照**

## 3. 被追问时的手牌（真实数字，敢给证据）

| 说法 | 证据 |
|---|---|
| 真往飞书推过 | 飞书返回 `code=0`；`alert` 表 `sent=1`；群里能看到「竞品A·蓝牙耳机：降价 12.6%（￥159.0 → ￥139.0）」 |
| 有测试 | `python -m pytest` → 25 passed；CI 跑 Ubuntu+Windows × 3.10/3.11/3.12 |
| 能离线复现 | `python -m price_radar demo` 不联网就能跑出 4 条告警（内置两个样例页） |
| 抓过真站点 | `books.toscrape.com` 公开练习站，取到 ￥51.77，`通过=css:.price` |

**不要吹的**：没有生产用户、没有 QPS/并发、没有大规模商品数、没做分布式。
一句"我就是自己用+练手，量级是几十个商品"比吹一个假数字安全得多。

## 4. 七个必被问 + 怎么答

1. **"这跟现成的监控插件有啥区别？"** → 现成插件大多只做"页面变了提醒你"；我做的是"比价格 + 按业务阈值判定 + 给跟价建议"，判定逻辑是纯函数、能单测。
2. **"页面改版了怎么办？"** → 四级降级先扛；真扛不住会发 `miss` 告警（而不是静默失败），改一个 selector 就恢复。
3. **"怎么防止重复刷屏？"** → 同类告警 24h 去重（`dedupe_hours`）+ 一轮只推一张卡片；抓取失败例外，因为它需要人立刻看。
4. **"为什么用 SQLite 不用 MySQL？"** → 单机、单写、数据量小（每商品每天 12 条快照），换 PostgreSQL 只动 `store.py`。够用就不上中间件。
5. **"怎么保证抓到的价格是对的？"** → 每次记录 `通过=css:.price / json-ld / regex`，一眼看出走了哪级；配 `our_price` 后异常值会体现为离谱的涨跌幅。
6. **"合规吗？"** → 只抓公开商品页、低频（2 小时一次）、带正常 UA、不做登录态爬取；不绕过任何风控。
7. **"你还能加什么？"** → 历史价格曲线、多平台同款聚合、企业微信/钉钉同款推送（notify 层换一个 adapter）、告警升级（连续 3 次未处理转人工）。

## 5. 三分钟现场演示脚本

```bash
python -m price_radar demo          # ① 不联网看判定结果（drop/undercut/sustained/oos）
python -m pytest -q                 # ② 25 passed
python -m price_radar report        # ③ 看 SQLite 里的价格历史
export FEISHU_WEBHOOK=...           # ④ 换成自己的机器人
python -m price_radar run           # ⑤ 真推一张卡片到飞书
```

## 6. 一句话总结（收尾用）

"它的价值不在爬虫，在**判定和降噪**：抓页面谁都会写，
难的是让运营一天只被打扰一次、每次打扰都带着可执行的价格建议。"
